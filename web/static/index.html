源码和公式的对应关系

源码小抄：分数、根号、上下标怎么写
  • \frac{a}{b} 是分数 ，把 a、b 换成题目里的数。
  • \sqrt{x} 是平方根 ；\sqrt[3]{x} 是三次根 。
  • x^{2} 是上标 ；a_{n} 是下标 。
  • \le 是 ≤，\ge 是 ≥，\pi 是 π。
  • 只改数字和字母；不要删掉 $、反斜杠 \ 和花括号 { }。

下面每个小框是题目里已经排好的公式，右边是它在源码中的写法。对照着改最不容易错。
